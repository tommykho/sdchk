## sdchk 0.1 - proof of concept (pre-release)

A Windows tool that checks whether a microSD card or USB drive really has the capacity it claims, and shows it on a map.

### WARNING - read before use
**This test writes test data into the free space of your card. If the card is FAKE and wraps around (it reports more capacity than it really has), these writes can OVERWRITE AND DESTROY EXISTING FILES. BACK UP ALL FILES FIRST. Use at your own risk: the software is provided without warranty of any kind (GPL-3.0-or-later), and the authors are not liable for data loss.**

sdchk saves the original content of every block it will overwrite to an undo journal on your PC (never on the card) and restores it afterwards, which protects your files in normal operation. A power cut or unplugging the card mid-test can still lose data.

### What it does
- Whole-card map, free space versus used space, journal of originals, writes unique data to ~50 areas spread over the card, reads them back in random order, scans for data that landed in the wrong place (wrap-around), restores everything and verifies the restore.
- Reports PASS / FAIL for capacity with an estimate of the real size, as `result.html` and `result.log` (command line) or in the UI.
- Command line also grades sustained write speed against the class printed on the card (C10, U1, U3, V30 ...) and 4 KiB random I/O.
- Simulated fake cards built in, so you can see how a fake is caught without any hardware.

### Run it
1. Download `sdchk-v0.1.0-win-x64.zip`, check the SHA-256 in the `.sha256` file, unzip.
2. Double-click `sdchk.exe` (or run `sdchk ui`). Your browser opens the map UI (local only, `127.0.0.1`). The exe is unsigned, so Windows SmartScreen may warn: choose *More info* then *Run anyway* if you trust the download.
3. Try a **demo card** first. For a real drive, pick *Real drive*, use *Restart as Administrator*, type `I UNDERSTAND`, and choose the card.
4. Command line: `sdchk list`, `sdchk inspect --drive F:` (read-only safety check), `sdchk check --drive F: --class U3`.

Windows 11 x64. No .NET install needed (self-contained).

### Known limits (please read)
- **The real-drive code path has not been run on real cards yet.** The release is built, tested and smoke-tested (simulated cards, UI start-up) on a GitHub Windows runner, but nobody has run it against physical hardware. Run `sdchk inspect --drive X:` first and use a card you can afford to lose.
- Only free clusters are written; before trusting the volume bitmap it proves the cluster-to-byte mapping with a 1 MiB calibration file (NTFS, exFAT, FAT32). If it cannot, it stops without writing.
- The size check is sampled: PASS means "no sign of fake capacity", not "every sector is good". Scattered bad sectors need a full test (planned).
- The speed test is command-line only in this version.
- Corroborate a dispute with a well-known tool (H2testw or f3) as well.

### Not included yet
Full bad-sector scan, speed test in the UI, instant 576-point screen, used-card confidence mode.
